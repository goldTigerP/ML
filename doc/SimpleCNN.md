# SimpleCNN（中文说明）

本文件列出了 `mnist_recognition/cnn_train.py` 中定义的 SimpleCNN 模型的逐层结构、每层输出节点数以及参数量（参数包括权重和偏置）。

模型概要（给出单样本的输出形状；参数计数包含权重与偏置）：

- 总参数量：1,199,882

按前向顺序的层列表：

1. conv1：Conv2d(1 -> 32, kernel=3, padding=0)
   - 输出形状： (1, 32, 26, 26)
   - 每样本输出节点：32 * 26 * 26 = 21,632
   - 参数：320（权重 32 * 1 * 3 * 3 = 288，偏置 32）

2. ReLU
   - 参数：0

3. conv2：Conv2d(32 -> 64, kernel=3, padding=0)
   - 输出形状： (1, 64, 24, 24)
   - 每样本输出节点：64 * 24 * 24 = 36,864
   - 参数：18,496（权重 64 * 32 * 3 * 3 = 18,432，偏置 64）

4. ReLU
   - 参数：0

5. MaxPool2d(2)
   - 将空间尺寸从 24x24 缩减为 12x12
   - 参数：0

6. Dropout2d(0.25)
   - 参数：0

7. Flatten -> 大小 64*12*12 = 9,216
   - 参数：0

8. fc1：Linear(9216 -> 128)
   - 输出形状： (1, 128)
   - 输出节点：128
   - 参数：1,179,776（权重 9216*128 = 1,179,648，偏置 128）

9. ReLU 与 Dropout(0.5)
   - 参数：0

10. fc2：Linear(128 -> 10)
    - 输出形状： (1, 10)
    - 输出节点：10
    - 参数：1,290（权重 128*10 = 1,280，偏置 10）

备注：
- 总参数 = 各层参数之和 = 1,199,882。
- 以上空间输出形状假设输入为 (1, 28, 28)。

FLOPs / MACs 分析（前向计算量）
- 定义说明：下面的计数以 MACs（multiply–accumulate，乘加次数）为单位。若按单独乘与加都计入 FLOPs，可近似视为 2 × MACs。

- 每层 MACs（单样本前向）：
   - conv1: 194,688 MACs
   - conv2: 10,616,832 MACs
   - fc1: 1,179,648 MACs
   - fc2: 1,280 MACs

- 总计（单样本前向）：11,992,448 MACs（约 11.99M MACs；约 23.98M FLOPs 若将乘与加分别计数）

备注：卷积层通常占据绝大部分计算量；上面的数值是在输入为 (1,28,28) 的单样本前向下测得。
