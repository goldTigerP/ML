# SimpleMLP（中文说明）

本文件列出了 `mnist_recognition/simple_train.py` 中定义的 SimpleMLP 模型的逐层结构、每层输出节点数以及参数量（参数包括权重和偏置）。

模型概要（给出单样本的输出形状；参数计数包含权重与偏置）：

- 总参数量：468,874

按前向顺序的层列表：

1. Flatten（展平）
   - 说明：将输入从 1x28x28 展平为 784
   - 参数：0
   - 输出节点（每样本）：784（中间表示）

2. fc1（线性层 784 -> 512）
   - 输出形状： (1, 512)
   - 输出节点：512
   - 参数：401,920（权重 784*512 = 401,408，偏置 512）

3. ReLU（激活）
   - 参数：0

4. Dropout（丢弃，p=0.2）
   - 参数：0

5. fc2（线性层 512 -> 128）
   - 输出形状： (1, 128)
   - 输出节点：128
   - 参数：65,664（权重 512*128 = 65,536，偏置 128）

6. ReLU 与 Dropout
   - 参数：0

7. fc3（线性层 128 -> 10）
   - 输出形状： (1, 10)
   - 输出节点：10
   - 参数：1,290（权重 128*10 = 1,280，偏置 10）

备注：
- 上述所有参数计数均包含偏置（如果存在）。
- 总参数为各层参数之和：468,874。

FLOPs / MACs 分析（前向计算量）
- 定义说明：下面的计数以 MACs（multiply–accumulate，乘加次数）为单位，常用于衡量卷积/线性等算子的计算量。若按单独乘与加计为 FLOPs，可近似视为 2 × MACs。

- 每层 MACs（单样本前向）：
   - fc1: 401,408 MACs
   - fc2: 65,536 MACs
   - fc3: 1,280 MACs

- 总计（单样本前向）：468,224 MACs （约 0.468 million MACs，约 0.94 million FLOPs 如果按乘加各计一次）

备注：激活（ReLU）、Dropout 等按位操作的计算量很小，通常不计入主要的 MACs 合计。
