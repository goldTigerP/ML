# ML
Machine Learning

- 第1周：深度学习速通 & PyTorch入门
  - 核心任务：理解神经网络核心概念（前向/反向传播、常见层类型），并熟悉PyTorch的基本操作。你的C++背景会让你对底层实现有天然的兴趣，这很好，但这一周重点是先学会“用”起来 。
  - 动手实践：用PyTorch训练一个最简单的MLP网络在MNIST数据集上做手写数字识别。跑通训练流程，并尝试修改网络层数，观察准确率变化 。
  - 关键输出：一个跑通的MNIST分类器代码。
- 第2周：深入模型核心——卷积神经网络 (CNN)
  - 核心任务：彻底搞懂CNN的卷积、池化、全连接层是怎么回事，以及经典结构（如ResNet）的巧妙之处 。
  - 动手实践：在CIFAR-10数据集上训练一个简单的CNN（可以自己手写一个），然后尝试加载一个预训练的ResNet18模型进行迁移学习（fine-tune）。重点关注模型的计算量（FLOPs）和参数量这两个概念。
