# ML
Machine Learning

 详细周计划
🚩 第一阶段：模型基础与“上帝视角”建立 (第1-4周)
这个阶段的目标不是成为算法专家，而是让你能读懂模型的“骨架”和“血流”，为后续的“动刀”优化打下坚实基础。
- 第1周：深度学习速通 & PyTorch入门
  - 核心任务：理解神经网络核心概念（前向/反向传播、常见层类型），并熟悉PyTorch的基本操作。你的C++背景会让你对底层实现有天然的兴趣，这很好，但这一周重点是先学会“用”起来 。
  - 动手实践：用PyTorch训练一个最简单的MLP网络在MNIST数据集上做手写数字识别。跑通训练流程，并尝试修改网络层数，观察准确率变化 。
  - 关键输出：一个跑通的MNIST分类器代码。
- 第2周：深入模型核心——卷积神经网络 (CNN)
  - 核心任务：彻底搞懂CNN的卷积、池化、全连接层是怎么回事，以及经典结构（如ResNet）的巧妙之处 。
  - 动手实践：在CIFAR-10数据集上训练一个简单的CNN（可以自己手写一个），然后尝试加载一个预训练的ResNet18模型进行迁移学习（fine-tune）。重点关注模型的计算量（FLOPs）和参数量这两个概念。
  - 关键输出：一个CIFAR-10分类器，并能够用torchsummary等工具打印出模型结构和参数量。
- 第3周：攻克Transformer——现代模型的基石
  - 核心任务：逐行理解Transformer的架构，特别是Attention机制 。这是理解大模型（LLM）和视觉Transformer（ViT）的必经之路。
  - 动手实践：精读并运行nanoGPT项目 。这是一个极简的GPT实现，代码量小，非常适合学习。在你的机器上用莎士比亚数据集训练一个mini版，感受文本生成的过程。重点关注KV Cache的实现和作用，这是推理加速的关键。
  - 关键输出：跑通的nanoGPT莎士比亚文本生成器，并写下你对KV Cache的理解笔记。
- 第4周：体系结构与并行计算复习
  - 核心任务：激活你作为C++开发者的“性能基因”。重点复习CPU缓存体系、SIMD指令（如ARM NEON, x86 AVX）、GPU的线程层次结构（Grid, Block, Warp）和内存模型 。
  - 动手实践：用NEON内嵌函数写一个简单的向量加法，对比普通C++实现的性能差异。如果条件允许，写一个基础的CUDA Kernel（如VecAdd），并理解其启动配置的含义。
  - 关键输出：一个性能对比测试报告（Markdown文档），包含代码片段和运行时间数据。
🚀 第二阶段：推理引擎与核心技术实战 (第5-10周)
这是最核心的阶段，你将亲手操作工业级的工具，把学到的理论转化为真正的“加速”能力。
- 第5周：模型导出与AI编译器初探
  - 核心任务：掌握模型从训练框架（PyTorch）到通用中间格式（ONNX）的转换，这是部署的第一步 。
  - 动手实践：将第2周的ResNet18模型导出为ONNX格式。使用Netron工具可视化ONNX模型，对比与PyTorch模型结构的异同。学习使用ONNX Simplifier等工具对模型进行初步简化。
  - 关键输出：成功导出的.onnx文件，并记录导出过程中遇到的算子兼容性问题及解决方案。
- 第6周：GPU加速的黄金标准——TensorRT入门
  - 核心任务：学习NVIDIA官方高性能推理引擎TensorRT的核心概念（如Engine, Context, Layer Fusion） 。
  - 动手实践：使用TensorRT的trtexec命令行工具，将第5周的ONNX模型转换为TensorRT引擎（FP32和FP16精度），并测试推理速度和内存占用。体验“一键加速”的效果。
  - 关键输出：trtexec的性能测试日志和对比分析。
- 第7周：深入TensorRT C++ API
  - 核心任务：发挥你的C++优势，学习如何使用TensorRT的C++ API构建推理程序，脱离Python环境，为车端部署做准备。
  - 动手实践：参考TensorRT官方 samples（如sampleMNIST），编写一个C++程序，实现从ONNX模型构建engine、反序列化engine、进行模型推理的完整流程。
  - 关键输出：一个完整的C++ TensorRT推理项目，能够正确加载模型并输出推理结果。
- 第8周：模型量化——精度与速度的博弈
  - 核心任务：深入理解量化的原理，特别是INT8量化 。理解校准（Calibration）的作用和不同校准方法（如熵校准、均方误差校准）的区别。
  - 动手实践：使用TensorRT的INT8量化功能，对ResNet18进行量化。你需要准备一个校准数据集。对比FP16和INT8模型的推理速度、显存占用和精度损失。
  - 关键输出：一份详细的量化实验报告，包含不同精度下的速度、显存、精度（Accuracy）数据。
- 第9周：拥抱大模型——Llama.cpp与端侧推理
  - 核心任务：学习大模型在端侧推理的利器——Llama.cpp 。它专注于CPU和移动端的优化，大量使用C++和底层优化技术，与你的背景完美契合。
  - 动手实践：编译并运行Llama.cpp，部署一个小的开源模型（如Qwen2-0.5B或TinyLlama）。尝试不同的GGUF量化格式（如q4_k_m, q8_0），对比其推理速度、内存占用和生成效果。深入阅读其底层实现了哪些优化（如内存布局优化、算子融合）。
  - 关键输出：一个在本地CPU上流畅运行的小型聊天模型，并写下你对GGUF量化和Llama.cpp优化的理解。
- 第10周：大模型推理优化技术纵览
  - 核心任务：系统学习针对大模型的推理优化技术，如Continuous Batching, PagedAttention, FlashAttention, Speculative Decoding 。理解它们是为了解决什么问题而生的。
  - 动手实践：尝试使用支持这些技术的推理框架（如vLLM）来部署一个稍大的模型（如Qwen2-7B），感受其在高并发下的吞吐量优势。虽然vLLM主要用于数据中心，但理解其原理对未来车端VLM/VLA的优化很有帮助。
  - 关键输出：对比vLLM与普通HuggingFace Transformers在吞吐量上的差异报告。
🎯 第三阶段：聚焦车端场景与深度优化 (第11-14周)
- 第11-12周：选定平台，深度调优 (以NVIDIA Orin为例)
  - 核心任务：选择一个主流车端芯片平台（推荐NVIDIA Orin，因为其资料丰富，TensorRT生态完善），深入研究其架构特性。
  - 动手实践：在Orin设备（或云端Orin环境）上，部署一个对车端有意义的模型，例如YOLOv5s/v8s用于目标检测 。使用TensorRT的性能分析工具（如Nsight Systems, Nsight Compute）对模型进行Profiling，找到性能瓶颈（如某个算子的耗时、数据拷贝开销），并尝试解决（例如，通过修改网络结构、调整数据预处理方式）。
  - 关键输出：一份详细的YOLOv5s在Orin上的Profiling报告和优化前后对比。
- 第13周：模型剪枝与知识蒸馏入门
  - 核心任务：了解更激进的模型压缩技术——结构化剪枝和知识蒸馏 。它们能从源头减小模型尺寸。
  - 动手实践：学习使用开源库（如torch-pruning）对一个小模型（如ResNet18的CIFAR-10版本）进行结构化剪枝，然后微调恢复精度。或者，尝试用一个训练好的大模型作为教师，蒸馏一个小型学生模型。
  - 关键输出：记录剪枝/蒸馏过程，对比压缩前后的模型大小和推理速度。
- 第14周：综合实践——部署一个多模态模型 (VLM)
  - 核心任务：挑战更复杂的视觉-语言模型（VLM） 的车端部署，这是当前智驾领域的热点。例如，部署一个能根据摄像头图像回答问题的模型。
  - 动手实践：选择一个相对轻量的VLM（如LLaVA的Phi-3版本或Fuyu-8B）。将其视觉编码器和语言模型分别/联合进行优化和部署（可以使用TensorRT或Llama.cpp的VLM支持），实现一个完整的图像输入->文本输出的推理pipeline。
  - 关键输出：一个能运行的VLM推理Demo，并记录其端到端延迟和内存占用。
🏆 第四阶段：项目集成与求职冲刺 (第15-16周)
- 第15周：打造你的王牌项目
  - 核心任务：将第14周的VLM项目进行打磨、封装，变成一个高质量的GitHub仓库。这是你求职时最有力的证明。
  - 关键行动：
    1. 代码重构：用C++封装核心推理引擎，提供清晰的接口。
    2. 文档编写：写一个详尽的README.md，讲清楚项目背景、方案选型（为什么选这个模型、为什么用这些优化手段）、运行效果（附上录屏或GIF）、性能数据对比（加速前 vs 加速后）。
    3. 博客撰写：将项目中的技术难点和解决方案写成一篇技术博客（发布在知乎、CSDN或个人博客上），展示你的思考和表达能力 。
